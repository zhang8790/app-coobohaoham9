# 推广侠客 · 内容锁客实操 SOP

> 适用：来电有喜 一级 / 二级推广侠客
> 可直接转发给所有推广会员阅读
> ⚠️ 本文所有话术已通过平台合规审核，请勿自行改成功效类说法

---

## 一、整体流程

```
找素材 → 素材工坊导入 → 大幅改写 → 套模板排版 → 插好物卡 + 免责声明
→ 预览发布 → 分享社群 / 朋友圈 → 访客阅读 → 点好物卡下单 → 推广佣金入账（金豆）
```

---

## 二、分步操作

### 步骤 1｜找素材，复制链接

- **渠道**：小红书、公众号、视频号、抖音
- **优先赛道**：家常汤方、时令食材、健康零食、家庭饮食参考
- 复制目标文章 / 视频的分享链接

### 步骤 2｜导入素材

创作中枢（底部中间 ⊕）→ **素材工坊** → 粘贴链接 → 点「解析」

- 系统会弹出**版权声明**，看完点「我已知悉，继续解析」
- 解析成功 → 图文自动进入**草稿箱**
- 解析失败（公众号、小红书常见）→ 在原文长按「全选 → 复制」，直接粘贴到输入框，一样能用

> ⚠️ **素材只是参考。不改直接发，会被投诉侵权、图文被下架。**

### 步骤 3｜标准化二次改编（必做）

**文字**
- 不要大段复制原文；读懂意思后，**全部用自己的话重新组织**
- 调整段落顺序，加入自己的个人感受
- 删除所有功效类词汇，统一换成「日常膳食搭配参考」

  ❌ 禁用：润喉、降火、降压、养胃、消炎、改善不适、治疗、调理
  ✅ 可用：日常膳食参考、家常搭配、时令食材、清爽口感、暖身汤方

- 系统会在发布时自动检测违规词，**命中会直接拦住不让发**，改好即可

**图片**
- 裁剪画面、调滤镜、加文字贴纸、换顺序
- **不要原图直接用**

**短视频素材**
- 提取文案 → 自己重写 → 配自己拍的图，做成图文

### 步骤 4｜排版、插好物卡与免责声明

1. 点「模板」→ 推荐选 **美食攻略**
2. 在合适位置点「好物卡」→ 选商品（银耳、百合、党参、牛肉食材、健康零食等）
   - 好物卡是**成交入口**，一篇建议插 1–2 个，插太多像硬广，反而没人点
3. 点「免责声明」→ 一键插入固定文本（**每篇都加**）

### 步骤 5｜预览发布

- 点「预览」看真实效果，检查文案和图片
- 确认无误 → 发布
- 发布成功可获得**金豆奖励**

### 步骤 6｜分发锁客

#### ① 微信群

直接发送小程序图文卡片，搭配文案：

> 换季很多朋友关心日常饮食搭配，整理了一篇食材参考，有需要的可以看看 👇

#### ② 朋友圈

发布后点「生成海报」→ 保存到相册 → 发朋友圈，配文：

> 日常膳食小分享，食材清单整理好了，扫码查看，按需挑选。

或

> 分享一篇饮食搭配心得，适合日常参考。
> 所有食材都是普通食品，理性选择，身体不适记得及时就医。

> 💡 **朋友圈只能发图片，不能直接发小程序卡片。** 所以必须用海报——海报右下角有小程序码，好友长按识别就能打开你的图文。

## 四、避坑提醒

1. **不要原样搬运**别人的原创图文，一定要二次改写，否则会被投诉下架
2. **不宣传任何治病、调理功效**，统一用膳食参考话术——这是平台红线，违规会限制发布
3. **不要诱导分享**（如「分享才能看」「集赞领奖」），违反微信规则
4. **一篇优质图文可以长期反复转发**，持续吸引新客户、持续产生订单

## 五、收益逻辑

```
你发的图文 → 好友打开（自动绑定你为推荐人）
→ 点击好物卡 → 下单成交
→ 你获得推广佣金（以金豆发放）
```

- **推广佣金以金豆形式发放，可在平台内消费，不可提现**
- 好友的好友再下单，你还能拿二级佣金（封顶两级）
- 在「我的创作」里可以看到每篇图文的：阅读 / 分享 / 好物点击 / 成单 / 佣金

**内容是资产。** 发一次，转发无数次，收益持续产生——这就是内容锁客和发朋友圈刷屏最大的区别。
