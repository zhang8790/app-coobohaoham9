# 敏感 / 高风险词汇替换对照表（项目合规基准）

> 适用范围：小程序商品文案 / 详情页 / 对外宣讲 PPT / 摊主话术 / 招商与合伙人物料。
> 原则：只讲食材特性、食用参考、生活调养，不涉及治疗、功效、病症断言；区分客观配料事实与主观食用建议。
> 本表已编码进代码强制拦截（见末尾「代码内强制拦截位置」），本文档可直接复制使用。

---

## 一、医疗疾病类禁止词 → 合规替换

| 禁止使用（违规） | 替换为合规表达 |
| --- | --- |
| 治疗、治愈、疗效、治病 | 日常食养、日常调养、饮食参考、食补调养 |
| 降压、降血压、降血脂、降糖 | 适合饮食管控人群食用、供饮食调理人群参考 |
| 抗癌、抗肿瘤 | 食材含有天然营养成分 |
| 预防 XX 病、防止 XX 疾病 | 日常膳食搭配选择 |
| 专治、改善病症 | 饮食上可作为一种选择 |
| 康复、修复身体 | 补充日常所需营养 |
| 排毒、解毒 | 帮助身体补充水分与营养 |
| 病灶、病症 | 身体状态 |

## 二、效果夸大类禁止词 → 合规替换

| 禁止使用（违规） | 替换为合规表达 |
| --- | --- |
| 特效、神效、奇效 | 风味佳，营养丰富 |
| 100%、百分百、保证、必定 | 根据个人体质因人而异，仅供参考 |
| 最好、第一、顶级（绝对化） | 优选、精选、严选 |
| 根治、根除 | 无（直接删掉，不做对应描述） |
| 强身健体、强肾 | 补充多种膳食营养 |

## 三、人群描述（高血压 / 慢病重点，小程序标签、商品详情高频）

- ❌ 适合高血压人群吃、可以降血压
- ✅ 供血压管控人群饮食参考，建议少量食用，结合自身情况取舍
- ❌ 适合糖尿病人食用
- ✅ 供糖分管控人群饮食参考，请留意配料碳水含量
- ❌ 儿童吃增强免疫力
- ✅ 适合孩童日常零食，均衡膳食更重要

**所有食品文案末尾统一加上兜底提示：**

> 温馨提示：本品为普通食品，仅作日常膳食食用，不具备调理疾病作用，食用请结合个人自身体质。

## 四、分销业务高风险词替换（招商、合伙人协议、小程序规则）

| 禁止（违规） | 合规替换表达 |
| --- | --- |
| 躺赚、稳赚、暴富、零风险赚钱 | 合理推广收益、推广劳务佣金、分享激励 |
| 静态收益、层级收益、拉人头奖励 | 销售推广佣金，仅基于真实商品成交计算收益 |
| 多级返利、无限代奖励 | 仅设置两级推广激励，佣金来源于商品实际销售订单 |
| 交钱获得资格、交钱升级 | 完成商品消费获得会员身份，不单独售卖推广权限 |

**核心规则**：佣金必须绑定真实成交订单，不能单纯靠发展人员拿奖励；禁止宣传无风险收益。

## 五、技术 / 内部文档 VS 对外展示区分（关键）

- **后台内部字典、研发文档**：可以保留专业术语（钠含量、钠超标、嘌呤、血脂相关分析），仅限团队内部看。
- **小程序前端、地摊物料、对外海报、摊主口头话术**：严禁直接输出专业诊断式结论，全部改用上面替换后的柔和提示语句。

## 六、食疗餐饮（牛肉党参枸杞汤这类套餐）商品上架完整示范（无违规版本）

- 标题：党参枸杞牛肉养生炖汤食材包
- 标签：家常食补食材、居家膳食组合
- 详情文案：
  > 精选牛肉、生姜、党参、枸杞组合，家常炖煮，感受食材本味，补充日常多种营养。
- 温馨提示：属于普通食品膳食食材，不同身体状态食用感受存在差异，仅供日常饮食享用，不作为身体调理方案，特殊身体情况请遵从专业人员建议。

## 七、流动地摊对外话术示例（给摊主，杜绝口头踩线）

- ❌ 不要讲：这个零食高血压吃很好，可以降压
- ✅ 标准话术：
  > “这款配料钠含量相对偏低，如果平时饮食需要注意血压，可以作为零食的其中一个选择，每个人体质不一样，可以少量尝尝。”

## 八、全套统一兜底模板（所有商品详情页末尾统一粘贴）

> 【食用温馨提示】本产品为普通食品，仅供日常膳食食用，不具备医疗调理作用。每个人体质不同，请结合自身情况选择食用；特殊身体状态请遵从专业人员建议。
