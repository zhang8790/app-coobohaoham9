## 三、MVP 产品形态（砍后的样子）

### 首屏 = 一个大扫描框
```
┌─────────────────────────┐
│   🍱 这包能不能吃？        │
│                          │
│   [  粘贴配料 / 拍照识别  ] │  ← 唯一主交互
│                          │
│   不卖的东西也能扫，免费  │  ← 信任钩子
└─────────────────────────┘
```

### 扫描结果页 = 评级 + 一句话结论 + 安全好物
```
安全评级：A · 含限量成分
─────────────────────
🟡 可适量食用
🔴 不建议给婴幼儿食用
适合：一般人群
不适合：对柠檬黄过敏人群
─────────────────────
🛒 为你推荐更安全的（3-5 个横滑 SKU）
```

## 四、用户路径（极简漏斗）

```
打开小程序
  → 扫码 / 粘贴配料（零门槛，不强制登录）
  → 看安全评级 + 一句话结论（信任建立）
  → 看"更安全的替代品"推荐
  → 下单（轻库存自营）
```

**关键设计：扫描动作对"非本平台商品"也免费开放。**
先当工具（扫任何零食都行），建立"它懂配料"的信任，再在自然位置推"我们卖的更安全的同款"。工具获客 → 信任 → 导购变现，路径最短。

---

## 五、冷启动策略（单城市 + 轻库存）

### 1. 地理聚焦：先打一座城
不要全国铺。选 1 座新一线/二线（如成都、杭州），本地内容投放 + 本地供应链，跑通后再复制。
理由：本地生活类冷启动，单城密度 >> 全国广度。

### 2. 货品：精选 50-100 个自营健康零食 SKU
- 模式：轻库存 / 一件代发，不压货
- 选品标准：本身配料干净（评级 S/A），能作为"扫出问题商品后的更优替代"
- 反例：不要一上来铺 2000 个 SKU 的百货

### 3. 获客：内容种草 → 引流扫码
- 小红书 / 抖音发"配料表避坑"内容（儿童零食、网红零食翻车实测）
- 钩子话术：「想知道你手里的零食安不安全？微信搜 XXX 扫一下」
- 工具天然适合短视频展示（30 秒扫出评级，视觉冲击强）

### 4. 冷启动数据资产已就绪
- 添加剂库 128 条直接可用，不需要重新积累
- 规避了情绪标签 / 食养标签的冷启动负担（MVP 不依赖它们）

## 六、验证指标（怎么算"跑通了"）

**北极星指标：周扫码次数**（不是注册数——工具价值先于账号价值）

| 漏斗环节 | 指标 | 跑通阈值（建议） |
|---------|------|----------------|
| 扫码 UV | 周扫码人数 | 先求 1000+/周 |
| 看完评级率 | 出结果后停留 >3s | > 70% |
| 点推荐好物率 | 扫后点推荐区 | > 25% |
| 加购率 | 点商品后进购物车 | > 10% |
| 首单转化 | 扫码 → 首购 | **> 3% 算跑通** |

> 3% 阈值参考工具类导购的常识区间，非精确值（⚠️ 推断）。
> 若扫码量大但转化 < 1%：说明"扫得动、买不动"，问题在货品/价格，需调选品。
> 若扫码量本身就起不来：说明获客钩子或工具价值不成立，需回炉定位。

## 七、风险与边界

| 风险 | 等级 | 应对 |
|------|------|------|
| 商品库空，无物可推 | 🔴 高 | MVP 启动前先铺 50-100 SKU，否则扫码闭环断 |
| OCR 配置不到位影响拍照体验 | 🟡 中 | 文本粘贴已兜底；OCR 作为增强而非必需 |
| 食品导购资质 / 功效宣称红线 | 🟡 中 | 代码已有 `FOOD_THERAPY_DISCLAIMER` 免责声明，保持"不建议替代医疗"措辞 |
| 添加剂库覆盖不全（常见零食命中"库未收录"） | 🟡 中 | 128 条够起步；运营侧持续补种子，命中未收录时引导用户反馈 |
| 二级分销合规（已砍，但代码残留） | 🟢 低 | MVP 阶段彻底不暴露分佣入口，规避食品+支付+分销叠加风险 |

## 九、对标参考（范式佐证，非核心支撑）

- **Yuka（法国）**：扫码评分配料 App，freemium 模式，公开报道千万级用户（⚠️ 待验证，单来源常识，建议核实精确数字）。它证明了"扫码 → 看成分评分 → 用户愿意用 → 会员/导购变现"的路径成立。
- **与 Yuka 的差异点**：Yuka 是纯工具不做电商；你来店有喜的稀缺性是**"扫完直接推更安全的同款并能买"**——工具+交易闭环是国内空白（见市场报告竞品对比：Yuka 可互补，小红书/美团/抖音不在该功能点直接竞争）。
