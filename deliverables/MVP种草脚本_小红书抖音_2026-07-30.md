# MVP 种草脚本：小红书 / 抖音

> 时间：2026-07-30
> 目的：给「来店有喜」配料安全扫描工具冷启动获客
> 平台：小红书为主（种草氛围强，女性/宝妈/白领用户集中），抖音为辅
> 风格：真实测评 + 制造反差感，不硬广

---

## 内容策略总纲

### 两条主轴

**轴 1：「网红零食配料翻车实测」**
- 逻辑：我帮你扫，你来看结果 → 反差越大传播越强
- 适合：辣条、薯片、软糖、奶茶、速食面等高认知品类

**轴 2：「超市常见零食配料红黑榜」**
- 逻辑：每天都在吃的东西，你真的看懂配料表了吗？
- 适合：儿童零食、早餐麦片、酸奶、坚果、饼干

### 内容形式优先级

| 形式 | 适合平台 | 制作成本 | 传播力 |
|------|---------|---------|--------|
| **配料翻车前后对比图** | 小红书 | 低 | 高 |
| **30 秒扫码视频** | 抖音/小红书 | 低 | 极高 |
| **横测长图文** | 小红书 | 中 | 中 |
| **直播扫码互动** | 抖音 | 高 | 极高 |

## 脚本 2：抖音 · 30 秒竖屏视频型

### 时长：28-35 秒
### 节奏：强开场 → 快速实测 → 意外结果 → 工具钩子

```
【0-3秒：强开场钩子】
（怼脸拍，表情惊讶）
"你知道你吃的辣条配料表里有什么吗？"
我扫了一下，吓到了

【4-10秒：快速实测】
（手机录屏，展示扫码过程）
贴配料表文字 / 拍照
（展示"正在解析"动画）

【11-20秒：结果冲击】
（截图放大，突出评级颜色）
安全评级：C · 含慎用成分
⚠️ 含 [具体成分名]
🔴 不建议给儿童食用

【21-28秒：工具留钩】
（切回本人）
微信搜「来店有喜」小程序
扫一下，30 秒就能知道
你手里的零食安不安全

（片尾字幕：30 秒学会看配料表）
#配料表 #食品安全 #辣条
```

### 拍摄建议
- **出镜**：不用专业主播，真实用户感更强
- **道具**：实物零食 + 手机截图
- **BGM**：轻快卡点，不需要说话时放着
- **字幕**：关键词加粗（评级、成分名）

## 脚本 4：抖音 · 超市横测直播型（进阶）

### 适用场景：抖音直播
### 形式：超市现场 / 直播间扫码互动

```
直播脚本（60 分钟场）

【0-5 分钟】开场
主播："今天我们在直播间现场扫配料表，
你们说什么零食，我就扫什么，
不删不改，扫完直接说结果。"

【5-40 分钟】弹幕互动
观众弹幕点单 → 主播当场扫
→ 念出评级 → 表情反应（惊喜/震惊/淡定）
→ 推荐店内干净替代品（如果有）

【40-55 分钟】教学环节
"配料表前三个最重要"
"看到这些名字要小心"（展示添加剂字典）

【55-60 分钟】工具转化
"这个工具叫来店有喜，微信搜一下就能用，
不用下载，下次逛超市前先扫一扫"

【字幕始终显示】小程序名称 + 搜索路径
```

### 直播关键 KPI
| 指标 | 目标 |
|------|------|
| 同时在线人数 | 500+ |
| 弹幕互动率 | > 30% |
| 小程序搜索量（直播后监测） | 对比直播前 +50% |
| 扫码 → 加购转化 | > 5%（工具属性强，可达） |

## 冷启动执行节奏

### 第 1-2 周：内容铺量
- 每天 1 篇小红书图文 + 1 条抖音短视频
- 集中打"网红零食配料翻车"话题（热度高）
- 不做付费推广，先测自然流量

### 第 3-4 周：数据复盘
- 哪篇/哪条数据最好（完播率/点赞/评论）
- 评论区有没有人问"怎么搜/怎么用"
- 有没有人主动说"我扫了 XX，也踩雷了"（UGC 苗头）

### 第 5 周起：迭代 + 加直播
- 根据数据最好的内容形式加大投入
- 开始做抖音直播扫码
- 小程序后台监控：周扫码 UV 是否 > 1000

## 注意事项

| 要点 | 说明 |
|------|------|
| **不攻击具体品牌** | 说"这款配料有问题"，不说"XX 品牌垃圾"（规避法律风险） |
| **工具留钩不强推** | "微信搜 XXX 就能用"，不提"快来买" |
| **UGC 鼓励** | 评论区引导："你扫了什么？评论区说说" |
| **真实不造假** | 扫描结果就是工具跑出来的，不用为了效果改数据 |
| **合规话术** | "食养参考，不替代医嘱"（已在代码里有 disclaimer，保持） |
