# 食疗安全提示 · 合规化显示方案

> 适用：来电有喜小程序「食疗安全分析」模块（详情页 / 商品卡 / 门店卡 / 首页 / 自营 / 人群弹窗）
> 结论：**完全隐藏"忌讳/注意"信息 = 不合规、有法律风险，不可取**；应采用「正向常驻 + 过敏强制显著 + 慎食折叠可查」的合规显示结构。

---

## 一、合规结论（先给答案）

| 项 | 是否允许 | 合规要求 |
|---|---|---|
| 只显示"适宜"、完全不显示"注意/忌讳" | ❌ 不允许 | 侵犯消费者知情权 + 违反警示义务 + 平台按"误导"处罚 |
| 正向"适宜参考"常驻前置 | ✅ 允许 | 真实信息，鼓励展示 |
| 过敏原（红标）强制显著常驻 | ✅ 必须 | 国标强制标示 + 法律责任，不可折叠/弱化 |
| 慎食/慢病（橙蓝）默认折叠、点击展开 | ✅ 允许 | 建议性质信息，须用户主动可获取、不可用色差字号"假隐藏" |

---

## 二、法规与平台依据（可溯源）

### 1. 食品广告不得涉疾病预防/治疗（《广告法》第17条 + 《食品安全法》第73条）
- 《广告法》第十七条："除医疗、药品、医疗器械广告外，禁止其他任何广告涉及疾病治疗功能，并不得使用医疗用语或易使推销的商品与药品、医疗器械相混淆的用语。"
- 《食品安全法》第七十三条第一款："食品广告的内容应当真实合法，不得含有虚假内容，不得涉及疾病预防、治疗功能。"
- 落地：本系统文案已通过 `sanitizeTherapyCopy` 把"降压"→"关注血压"等硬替换，**不得写任何功效/治疗断言**。

### 2. 过敏原强制标示（GB 7718-2025，2027-3-16 实施；趋势已是强制义务）
- 八大类致敏物质（麸质谷物、甲壳类、鱼类、蛋类、花生、大豆、乳、坚果）作为配料使用时**必须强制标注**（加粗/下划线/独立提示语）。
- 微信小店《网络食品虚假宣传问题专项治理》亦将"过敏原/不适宜人群提示"列为合规要点。
- 落地：**过敏原红标在详情页与商品卡均强制显著常驻**，不可隐藏、不可靠色差弱化到看不见。

### 3. 消费者知情权与警示义务（《消费者权益保护法》第8、18、20条）
- 第8条：消费者享有知悉商品真实情况的权利。
- 第18条：对**可能危及人身、财产安全**的商品和服务，经营者应向消费者作出**真实的说明和明确的警示**。
- 第20条：经营者提供商品信息应真实、全面，不得作虚假或引人误解的宣传。
- 落地：**"忌讳"信息不能全隐藏**——过敏是危及人身安全（严重可致死），必须警示；慎食/慢病属建议性质，可弱化但须可获取（折叠展开），不属于"隐瞒"。

### 4. 小程序上线合规红线（微信小程序 / 微信小店平台规范）
- 专项治理明确查处的情形包括："利用字号大小、色差、版面设计等方式误导用户"，以及"明示或暗示食品具有疾病预防、治疗功能"。
- 关键判断：**"弱化" ≠ "用色差/字号隐藏"**。折叠必须是"用户主动点击可展开的真折叠"，过敏提示必须显著，否则平台会判定为误导式版面设计违规。

## 三、已落地的合规显示结构

### 详情页「🔍 食疗安全分析」卡
1. **✅ 适宜参考**（绿色区块，常驻前置）—— 由食材字典 `fit_scenes` 真实聚合，给正向信号。
2. **🔴 过敏原警示**（红框，强制常驻、不可折叠、不可弱化）—— 满足警示义务与国标。
3. **🍃 食用注意（N）**（灰框，默认折叠）—— 慎食/慢病建议项，点"查看详情 ›"展开，信息可获取但不喧宾夺主。
4. **📣 商家食养寄语 + 免责声明**（常驻）。

### 商品卡（首页 / 自营 / 门店 / 横滑，复用同一组件）
- 整体性味 chip + **✅ 适宜** chip 常驻；
- 仅常驻 **🔴 过敏** 红 chip（强制硬提示，带边框）；
- 慎食/慢病**不进列表**（进详情页主动展开查看），避免列表靠红橙蓝铺满吓退用户，同时不违反"可获取"原则。

### 人群弹窗
- 首句正向引导 + 过敏硬提示保留（不软化法律责任级信息）。

## 四、开发 / 运营红线（必须遵守）

1. **禁止任何疾病预防/治疗/功效断言**（降糖、抗炎、治咳等）。新增文案必须过 `sanitizeTherapyCopy`。
2. **过敏原必须基于真实配料**，不可编造、不可漏标（漏标 = 违反 GB 7718 + 消法警示义务）。
3. **不得用极小字号 / 极低对比度**让提示"看得见等于看不见"——微信平台按"误导"处罚。
4. 折叠区域必须是**真折叠**（用户可点开查看完整信息），不能是视觉上隐藏、实际不可达。
