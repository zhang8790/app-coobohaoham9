# MVP 商品种子数据：选品框架

> 时间：2026-07-30
> 目的：指导 50-100 个自营 SKU 的初期选品，确保"扫完有替代品可推"闭环成立
> 范围：轻库存 / 一件代发模式，不压货

---

## 一、选品原则（三条铁律）

**1. 先有评级，再上架**
每个 SKU 上架前，必须用「来店有喜」自己扫一遍，配料干净的才进库。
目的：确保推荐区的每一个"更安全的替代品"真的有更低的配料风险。

**2. 只选"扫完有对手的品类"**
目标品类 = 超市里配料表容易被"打脸"的零食。
反例：大米、矿泉水（太干净，扫了没替代意义）。

**3. 首批 50 个 SKU 按场景分 6 类**
每个场景 7-10 个，覆盖用户最常踩的坑。

---

## 二、六类场景 × 推荐品类

### 场景 A：儿童零食（最容易踩坑，家长最敏感）
> 用户画像：有 3-12 岁孩子的家长，关注配料但看不懂配料表

| 品类 | 常见问题 | 选品标准 |
|------|---------|---------|
| 儿童饼干/小馒头 | 含柠檬黄、日落黄（你的黑标） | 无人工色素，S/A 评级 |
| 儿童肉肠 | 含亚硝酸钠、卡拉胶 | 无防腐剂，S/A 评级 |
| 果泥 / 儿童酸奶 | 含明胶、香精、增稠剂 | 无香精、低糖，S/A 评级 |
| 小面包/蛋糕 | 含丙酸钙、脱氢乙酸钠 | 无防腐剂，S/A 评级 |
| 奶酪棒 | 含卡拉胶、色素 | 天然奶酪，无添加，S/A 评级 |

**上架前自测话术**（用于内容种草）：
> "我们上了 XX 款儿童零食，每一款上线前我们自己先扫一遍，把有问题的全踢掉了。"

---

### 场景 B：网红零食（小红书/抖音带火的爆款，用户最想验证）
> 用户画像：刷到博主推荐，想知道这东西到底能不能吃

| 品类 | 代表产品 | 选品标准 |
|------|---------|---------|
| 辣条/素肉 | 某龙、某龙兄妹版 | 低添加剂版本 S/A，替代原版黑标 |
| 燕麦奶/植物奶 | 某麦星球、某轻时刻 | 无增稠剂/香精版本 |
| 蛋白棒/代餐棒 | 某缐、某叫兽 | 低糖、低添加剂版本 |
| 龟苓膏/凉茶即食 | 某老吉即食版 | 无糖/低糖版 |
| 维生素软糖 | 某健康、某加能 | 无人工色素版 |

**关键逻辑**：不否定网红零食，而是推"同款干净版"——冲突感强，种草内容好写。

---

### 场景 C：调味坚果 / 每日坚果（配料看似干净，实际有坑）
> 用户画像：健身/减脂人群，认为坚果很健康

| 品类 | 常见问题 | 选品标准 |
|------|---------|---------|
| 盐焗坚果 | 钠含量爆表、人造香精 | 轻烘焙/无盐版本，S 评级 |
| 每日坚果小包装 | 含白砂糖/麦芽糊精 | 纯坚果，无糖/无添加 |
| 坚果酱（花生/杏仁） | 含氢化植物油、糖 | 纯坚果酱，无添加 |
| 奇亚籽/亚麻籽 | 含糖/香精的即食版 | 无添加版本 |

---

### 场景 D：冲调/代餐（办公室场景，早上和下午最高频）
> 用户画像：白领，想吃得健康但懒得做

| 品类 | 常见问题 | 选品标准 |
|------|---------|---------|
| 即食麦片 | 含植脂末、氢化椰子油（反式脂肪） | 纯麦片/无植脂末版 |
| 黑芝麻糊/核桃粉 | 含白砂糖、麦芽糊精 | 纯谷物/低糖版 |
| 速溶咖啡/冷萃液 | 含乳化剂、卡拉胶 | 纯咖啡/无添加版 |
| 藕粉/葛根粉 | 含增稠剂、甜味剂 | 纯藕粉/无添加版 |

---

### 场景 E：饼干/糕点（配料表最复杂，普通消费者最难读懂）
> 用户画像：零食爱好者，对添加剂见怪不怪但内心担忧

| 品类 | 常见问题 | 选品标准 |
|------|---------|---------|
| 苏打饼干 | 含碳酸氢钠（小苏打）做膨松剂 | 无碳酸氢铵/改良剂版 |
| 曲奇饼干 | 含氢化植物油（反式脂肪风险） | 无氢化油，纯黄油版 |
| 威化饼干 | 含磷脂、山梨酸钾 | 低添加剂版 |
| 月饼/蛋黄酥 | 含脱氢乙酸钠（防腐剂） | 短保版（防腐剂非必须） |

---

### 场景 F：饮料/即食（最后加的，补充场景完整度）
> 用户画像：夏天/运动后随手买

| 品类 | 常见问题 | 选品标准 |
|------|---------|---------|
| 瓶装茶饮 | 含苯甲酸钠/山梨酸钾 | 无防腐剂版/纯茶 |
| 乳酸菌饮料 | 含白砂糖/糖醇 | 低糖/无添加版 |
| 凉茶/草本饮料 | 含糖精钠/阿斯巴甜 | 无甜味剂版 |
| 气泡水 | 含代糖/柠檬酸 | 纯气泡水/无添加版 |

## 三、上架 SOP（每个 SKU 必须走一遍）

```
Step 1：用「来店有喜」自己扫一遍
  → 评级 S/A → 进候选池
  → 评级 C/D → 暂不上，或找干净替代品

Step 2：填 Supabase 商品表关键字段
  ┌────────────────────────────────────────────────┐
  │ 必填字段（扫描引擎直接用）                      │
  │  ingredients     TEXT[]   ← 配料表原文          │
  │  allergens      TEXT[]   ← 致敏原 key 列表      │
  │  nutrition      JSONB    ← {energy_kj, protein,  │
  │                              fat, carb, sugar,  │
  │                              sodium}            │
  │  safety_grade   CHAR(1)  ← 'S'/'A'/'C'/'D'      │
  │  safety_summary JSONB    ← 分析报告缓存          │
  │                                                  │
  │  选填字段（推荐引擎用）                          │
  │  overall_nature VARCHAR  ← '平'/'温'/'凉' 等    │
  │  health_tag     TEXT[]   ← ['护胃','补血'] 等   │
  └────────────────────────────────────────────────┘

Step 3：拍商品图（干净白底 + 配料表截图）
  → 方便用户"扫完顺手看到长什么样"

Step 4：定价（参考思路）
  自营无中间商，定价 = 成本 × 2~2.5（参考电商普遍倍率）
  不要比超市贵太多，用户扫码后发现"同款便宜的更多"会流失
```

## 四、供应链建议（轻库存模式）

| 模式 | 说明 | 适合阶段 |
|------|------|---------|
| **一件代发**（推荐起步） | 供应商直接发，有订单才发，无库存压力 | MVP 前 3 个月 |
| **小批量囤货** | 爆款 SKU 备 20-50 件，降低单件成本 | 周复购验证成立后 |
| **OEM 定制** | 自定配方找工厂代工，自有品牌 | 有稳定月销 > 500 单后 |

**首批供货商筛选渠道（按成本低 → 品质可控排序）：**
1. **1688 找"零添加"/"清洁配料"供应商**（关键词：清洁标签、零添加食品）
2. **有赞 / 微店的分销市场**（已有品控的供货商）
3. **地方特色食坊**（手工零添加小品牌，故事性好，适合内容种草）

## 六、数据资产价值（越卖越值钱）

每个上架商品的配料数据（`ingredients` + `safety_grade`）积累后：
- **商品越多，扫描命中率越高** → 用户体验越来越好
- **用户扫描历史数据** → 可以分析"哪类食品踩坑最多" → 反哺内容选题
- **与供应商谈判的筹码** → "我平台帮你卖，数据告诉我哪款卖得好"

## 七、风险

| 风险 | 缓解 |
|------|------|
| 供应商货不对版（说无添加，实际有） | 上架前每批自己扫码抽检 |
| SKU 太多管理不过来 | 先 30 个，跑通再加 |
| 定价偏高流失用户 | 参考超市价，倍率不超过 2.5× |
