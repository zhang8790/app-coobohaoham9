三、逐功能深度对标与借鉴建议

🔬 功能一：AI配料扫描/分析

我们现状：已有 ingredient-analyze EF + 四档安全评级 + 配料安全库。前端 food-scan 页 + 标准报告页。

📊 竞品亮点

  • 酸果湾：拍配料表→1秒出结果，三层输出（风险红色高亮→配料解析→人群标注「孕妇慎吃」），还支持两款产品VS对比，扫完立刻推荐替代商品
  • 成分快查：用户可自定义评分规则（调权重/加减分项），开放评分逻辑，极度透明
  • 好食助手：每种添加剂一张独立信息卡片（功能+安全等级+每日上限+适用人群），可视化设计
🎯 我们的改进方向（按优先级）：
P0 报告可视化升级——每种添加剂/过敏原呈「卡片式」而非纯文字列表（好食助手模式），每卡含：名称+功能+安全等级颜色条+风险说明+适用人群建议
P0 扫码→购物闭环——配料分析报告底部增加「推荐替代商品」模块（酸果湾核心体验），直接关联匹配度最高的店铺商品
P1 产品对比功能——在报告页增加「VS对比」按钮，选另一款扫描过的商品做横向对比
P2 自定义关注项——让用户标记自己关心的成分类型（如色素/防腐剂/过敏原），分析时加重权重

🎨 功能二：安全评级可视化

我们现状：四档评级（A优选/A含限量/B适度慎选/C不推荐），有标准JSON输出。但前端渲染仍是文字列表为主。

📊 竞品亮点

  • 成分快查：百分制评分 + 五级颜色标识（绿色A/蓝色B/黄色C/橙色D/红色E），一眼可感知
  • 酸果湾：红黄绿三色风险标注，争议成分直接高亮+附解释，不给简单的「能吃/不能吃」
🎯 我们的改进方向：
P0 总评大数字+颜色条——报告顶部放置一个大的安全综合评分（参考成分快查百分制），用渐变色环/条渲染，配一句话总结（如「该产品A级优选，适合儿童食用」）
P1 扣分溯源链路——点击每个扣分项，弹出说明「为什么扣分？参考哪个标准？针对哪类人群？」（成分快查的透明度设计）

🛍️ 功能三：商品内容（首页/商品卡片/详情页）

我们现状：首页有商品卡片（ProductGridCard），商品详情页，商家商品列表（merchant-products）。

📊 竞品亮点

  • 秋田满满：每个商品页面带分龄标签（适合6M+/9M+/12M+），配检测报告二维码，扫码直达SGS报告
  • 宝宝馋了：商品页展示原料产地实拍+生产车间图，消除「黑箱生产」顾虑
  • 青禾营养餐：商品卡上打场景标签（健身控卡/宝妈首选/儿童适宜），用户一键按场景筛选
  • 酸果湾：每个商品标注有机认证+区块链溯源编号
🎯 我们的改进方向：
P0 商品卡片升级——每张商品卡须展示三个关键信息：安全评级色标 + 适配人群标签 + 配料洁净度（几项0添加）
P0 详情页信任区——页面底部固定「安全保障」模块：配料分析报告入口 + 检测报告（如有）+ 过敏原声明
P1 按场景筛选——首页顶部增加快捷筛选 pill：儿童适宜/健身控卡/无添加剂/低糖/孕妇可用
P2 产地溯源页——核心SKU增加溯源信息（产地实拍+原料说明），参照秋田满满

🏅 功能四：会员段位体系（凡心→无心境）

我们现状：六层段位体系（凡心/初心/明心/静心/悟心/无心境），国潮命名，有对应的健康豆和权益。这是我们的核心差异化优势。

📊 竞品亮点

  • 青禾营养餐：分销晋升体系（青铜→铂金→王者），每个等级解锁实物奖励+专属课程+品牌周边
  • 行业最佳实践：等级不宜过多（3-4级最佳），可视化成长进度条（距下一级还需多少）
  • 滋补品会员：钻石会员享私人养生定制、优先发货、专属时段
🎯 我们的改进方向：
P1 成长可视化——个人中心展示段位进度条+「距下一级还需X健康豆/消费X次」，给用户明确升级目标
P1 段位差异化权益显性化——每个段位解锁一个独特权益，在商品页/结算页以badge展现（如「明心段位专享9折」）
P2 段位专属内容——高段位解锁专属食养内容/专家讲座，强化「高人一等」的尊贵感
P2 段位称号炫耀——允许用户在商品评价/社区中展示段位title，驱动社交传播

💰 功能五：分销/佣金体系

我们现状：两级分佣（一级好友/二级粉丝），每单幂等，佣金转健康豆不可提现。计算器已迭代到v5。

📊 竞品亮点

  • 青禾营养餐：直推15-20% + 团队奖金5-10% + 晋升体系（青铜→王者），高等级分销商获营养师认证课程+品牌周边
  • 颜之堂：三级代理架构（省市代理/门店/个人），不同层级不同拿货价和佣金比例，云仓一件代发
  • 江中食疗：「分享官中心」实时查看业绩/排名/提现，结算透明
  • 行业数据：某快消品牌接入分销后，6个月发展2000+分销员，订单增长40%
🎯 我们的改进方向：
P0 分销员中心（Dashboard）——实时展示：我的佣金/团队业绩/推广订单/排名/提现记录（参照江中食疗「分享官中心」）
P1 分销晋升激励——按业绩分层级，高等级获更多权益（更高佣金比例/专属推广素材/优先发货等）
P1 一键生成推广素材——为分销员提供商品海报、文案模板、分享卡片，降低推广门槛
P2 排行榜+竞赛——月度/季度分销排行榜，Top10额外奖励

🫘 功能六：健康豆体系

我们现状：健康豆 1:1 锚定人民币，购物返豆+分佣返豆，不可提现。有 BeanHud 组件展示余额。

📊 竞品亮点

  • 青禾营养餐：阶梯储值返利（充200送25=12.5%，充1000送200=20%），吸引大额锁定
  • 行业最佳实践：积分获取来源不应仅限于消费——签到、分享、评价、完善资料均应积
  • 积分商城：100积分换5元券、500积分换实物小样，低门槛高感知
  • 积分到期提醒：快过期时推送，刺激消费
🎯 我们的改进方向：
P0 健康豆获取多元化——每日签到得豆（连续签到递增）、分享商品得豆、写评价得豆、完善档案得豆
P1 健康豆商城（兑换专区）——专区展示可兑换商品/优惠券/服务，降低使用门槛
P1 健康豆+现金混合支付可视化——结算页清晰展示「健康豆抵扣X元 + 微信支付X元」（参照 payment 页已有基础，增强可视化）
P2 健康豆任务墙——首页/个人中心展示可赚豆的每日任务，游戏化运营

🧘 功能七：AI食养/食疗

我们现状：产品疗法报告（product-therapy.ts 三色预警），consult页面AI对话，情绪编译EF。有完整食疗引擎。

📊 竞品亮点

  • 酸果湾：AI营养师对话框——引导式问答（你的体重？生活习惯？饮食偏好？），然后给出针对性营养建议，而非泛泛而谈
  • 酸果湾：未来规划扫脸/扫舌苔/测热量等趣味交互，用轻量化互动降低健康门槛
  • 江中食疗：按症状组织UGC——「胃不舒服吃什么」「上火怎么办」，用户看到真实评价自然转化

🎯 我们的改进方向：

P1 按症状/场景导航——首页增加「按需求找」入口：过敏体质/控糖/增强免疫/儿童成长 → 推荐商品+食疗方案
P2 趣味健康工具——BMI计算器/食物热量查询/每日营养打卡等轻量工具，吸引日常打开

⏰ 功能八：保质期预警

我们现状：有保质期预警EF（expiry-engine），这是全竞品独一无二的功能。但前端展示和执行程度待验证。

📊 竞品亮点

  • 乔拓云/万象：B2B进销存SaaS，临期预警+FIFO先进先出+多渠道提醒（短信/小程序/后台弹窗三重）
  • 生鲜行业：按品类自定义预警时间（绿叶菜24h、肉类48h、干货7天），批量导入+自动生成预警表
🎯 我们的改进方向：
P0 用户端临期提醒入口——个人中心增加「我的食品管家」入口，展示已购商品的临期状态（正常/临期/已过期），主动推送提醒
P1 临期商品专区（清仓）——首页开设「临期特惠」区，既消化库存又让利用户，参照生鲜行业
P1 购买时智能提示保质期——商品详情页展示「此商品保质期XX天，建议XX前食用」，下单时提醒

🔘 功能十二：每个按钮都发挥价值——全页按钮审计

用户要求：「每个功能、每个按钮都需要发挥出来左右」。

📊 按钮设计最佳实践

  • CTA按钮：每个页面只应有 1个主按钮（最强视觉权重），其他为次要按钮或文字链接。主按钮颜色须统一使用品牌金色。
  • 商品卡按钮：「立即购买」vs「加入购物车」vs「查看配料」——应有优先级区分，主按钮≠购物（竞争品），应是「查看配料分析」作为核心差异化动作
  • 分享按钮：分销推广场景下，分享按钮应醒目（浮动按钮或商品页固定底栏），含「分享赚健康豆」文案
  • 空状态按钮：列表为空时不是展示空白页，而是引导按钮（如「去逛一逛」「扫描第一个商品」）

七、核心结论

1. 来电有喜不是没有优势——而是优势太散，缺一个「主线」串联。
我们有业界最完整的 「配料分析+食养引擎+会员段位+分销+保质期+门店O2O」六位一体，全竞品无人能及。但体验是「零件很好、整车没组起来」——各功能各自为战，缺乏统一的产品故事线和用户旅程。

2. 最关键的破局点：把「分析配料」变成「推荐购买的理由」。
酸果湾的成功逻辑是「扫码→识风险→推荐安全替代商品→购买」一条龙。我们的配料分析已经有，但分析完就没了——缺最后一公里（推荐商品）。补上这个闭环，每个分析报告都是一张商品导购页。

3. 信任可视化是定价权的基石。
秋田满满卖得贵（且卖得好），靠的不是便宜——是每盒产品可扫码看SGS报告。我们应该把配料安全库的数据规模、分析准确率、检测标准做成可视化信任页面，让用户知道「为什么这里买更安心」。

4. 分销员需要「被服务」，不只是「被分佣」。
当前分销体系只看金额——缺推广工具、缺晋升激励、缺业绩可视化。青禾营养餐的分销员晋升+专属课程+排名系统，是激发分销员长期活跃的关键。

5. 每个按钮，都能讲一个故事。
当前按钮的逻辑是「功能驱动」（点这里可以干嘛），竞品的逻辑是「价值驱动」（点这里你能获得什么安全感/实惠/知识）。按钮文案、位置、视觉权重都应服务于用户价值的即时感知。
